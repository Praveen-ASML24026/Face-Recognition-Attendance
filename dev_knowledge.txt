TIMESTAMP: 2026-11-04 19:01:00 IST
ACTION: Comprehensive architectural audit and gap analysis of the Face Attendance System

NOTES / FINDINGS:
Identified 6 critical architectural and functional gaps for enterprise production readiness:
1. Anti-Spoofing & Liveness Detection (PAD): No defense against presentation attacks (holding up photos, phones, or tablet screens).
2. Multi-Course / Section / Class Hierarchy: All enrolled students exist in a single flat namespace; lacks course, section, and timetable scoping.
3. Asynchronous Job Processing (Celery/Redis): High-resolution quadrant tiling and ArcFace inference run synchronously on the HTTP thread, risking gateway timeouts.
4. Live Capture & RTSP IP Camera Streaming: System requires manual file upload rather than direct browser webcam snapshot or classroom IP camera feed.
5. Analytics & Automated Notifications: Missing student attendance percentage tracking (<75% eligibility warning) and absent alert dispatch (Email/SMS).
6. Vector Search Indexing (FAISS) & Production DB: Linear cosine similarity scan scales at O(N); requires ANN indexing and PostgreSQL for enterprise scale.
